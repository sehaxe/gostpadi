# web

Исходник веб-приложения:

- `index.html` — разметка и плейсхолдеры для CSS/JS;
- `style.css` — стили;
- `main.js` — логика, протокол wasm и приём файлов.

`docs/app.html` — собранный артефакт. После правок в `web/`:

```bash
node web/build.mjs
```

CI собирает его перед публикацией (`pages.yml`). Руками `docs/app.html`
не правим — следующий билд перезапишет.
