Блок-схема из кода —
за две с половиной миллисекунды

Вставьте main.c — получите настоящий лист А4 210×297 мм с полями ЕСКД: ромбы 45°, циклы шестиугольником «подготовка», параллелограммы ввода-вывода, линии строго под 90°. Всё считается в браузере, код никуда не отправляется.

Инструмент для лабораторных — это инструмент для кода, который ещё не дописан.

tree-sitter

Битый код рисуется, а не отказывает

Строгий парсер C99 на одной незакрытой скобке завершался ошибкой и не рисовал ничего. Сейчас разбор помечает непонятное и рисует то, что понял. Схема получается всегда.

sheet.rs

Настоящий лист А4

210×297 мм, поля ЕСКД 30/10/20/20 мм, текстовая зона 170×257 мм. Длинные схемы режутся на листы с кружками-соединителями. Размер страницы не зависит от содержимого.

пачка

Один масштаб на всю лабу

gostpadi 1/*.c 2/*.c -o out/ — размер фигур, масштаб и лист общие для всех файлов, как требует п. 4.1.3 ГОСТ. Если масштаб упал ниже читаемого, утилита об этом говорит.
