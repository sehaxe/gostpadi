# Политика break и continue: рельса, а не блок; break покидает только switch

Схемы по ГОСТ 19.701 рисуются из кода студентов, где break/continue встречаются
в трёх контекстах: тело цикла, ветка if внутри цикла, кейс switch (иногда
внутри цикла). Один разбор показал, что строка `break` в трёх контекстах
рисовалась тремя разными способами, два из которых врали о потоке управления:
выход из цикла вместо выхода из switch, провал в следующие операторы после
continue. Решили: **блок break/continue не рисуется никогда** — переход
изображается линией.

## Правила

- **break при внутреннем scope «цикл»** — рельса в левый канал, вниз мимо
  нижней трапеции, T-стык на продолжении (выход из цикла).
- **break при внутреннем scope «switch», напрямую в кейс-колонке** —
  растворяется: конец кейса и штатное слияние кейса уже изображают переход.
  Схема с `; break` в кейсах посимвольно совпадает со схемой без них.
- **break при внутреннем scope «switch», вложенный (if внутри кейса)** —
  рельса к выходу switch: в C он пропускает остаток кейса, но не цикл.
- **continue** — рельса к выходу нижней трапеции цикла (T-стык на отрезке
  «loop_end → продолжение»): следующая итерация. switch continue не
  перехватывает. Инструкции колонки после break/continue не рисуются —
  они недостижимы.
- **Вход в колонку, состоящую из break/continue, рисуется без стрелки**:
  стрелка в пустоту запрещена, направление ведёт рельса или слияние.
- **Вне цикла и switch** (валидность не проверяем) break/continue остаются
  обычными плитками — прежнее поведение для брошенного текста.

## Consequences

- Колонка, чей поток ушёл рельсой, не дорисовывается к шине слияния своего
  ромба (раньше это давало вторую линию у ветки «да» и ложное «возврат в
  цикл» на схеме).
- Готовые схемы меняются: прямоугольники «break» в кейсах исчезают, плотность
  рядов сетки switch растёт (кейсы короче на высоту плитки).
- Скрытая инварианта: `loop_depth`/`switch_depth`/`case_direct` образуют
  протокол «кто владеет рельсой»; владелец — внутренний scope, он же дренирует
  очередь рельс при выходе из scope.

## Considered Options

- Рисовать видимый прямоугольник break с выходом на рельсу — отклонено:
  отдельного символа break в ГОСТ 19.701 нет, а требования «нужен блок»
  встречаются редко и решаются правкой .gvn.
- Оставить как было и объяснять картинки словами — отклонено: схема обязана
  читаться преподавателем без объяснений.
