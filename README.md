# gostpadi

**Блок-схемы по ГОСТ 19.701 из кода на C — без рисования руками**

Скармливаешь `main.c` — получаешь готовую схему: линии под 90° и одной
толщины, стрелка на входе в каждый блок, длинные схемы сами режутся
на листы А4.

## Зачем

Курсовые и лабы требуют схемы по ГОСТ, а рисовать их в редакторе — боль.
`gostpadi` делает это сам:

- **Из кода** — парсит C (`if`/`else`, `switch/case`, `while`/`for`/`do-while`,
  `return`, `printf`/`scanf`) и строит схему;
- **Из текста** — свой формат `.gvn`: одна строка = один блок, полный
  контроль над схемой;
- **По ГОСТ 19.701-90** — ромбы 45°, циклы шестиугольником «подготовка»,
  параллелограммы ввода-вывода, модульная сетка 5 мм;
- **В А4** — настоящий лист 210×297 мм с полями ЕСКД (30/10/20/20 мм);
  длинные схемы режутся на листы с кружками-соединителями
  (`--no-split` — наоборот, вся схема одним листом в масштабе пачки);
- **Пачкой** — `gostpadi 1/*.c 2/*.c -o out/`: блоки во **всех** схемах
  одного размера, как и требуют правила оформления отчёта.

Работает и в обратную сторону: короткий текстовый файл `.gvn` —
и та же схема без кода.

## Установка

```bash
cargo install --git https://github.com/sehaxe/gostpadi
```

Или готовый бинарник под Linux / macOS / Windows —
в [релизах](https://github.com/sehaxe/gostpadi/releases).

Сборка из исходников:

```bash
git clone https://github.com/sehaxe/gostpadi && cd gostpadi
cargo build --release
# бинарник: target/release/gostpadi
```

## Использование

```bash
gostpadi main.c -o main.svg            # код C -> main.svg
gostpadi scheme.gvn -o s.svg           # готовая схема из .gvn
gostpadi 1/*.c 2/*.gvn -o out/         # пачка: каждой схеме свой .svg
gostpadi scheme.gvn --labels=ru        # надписи «начало/конец», «да/нет»
gostpadi scheme.gvn --check            # только проверка, без рисования
```

Суффикс имени определяет режим: `.c` — код, всё остальное — `.gvn`.
Результат — чистый векторный **SVG** (в Word/LaTeX/браузер без потерь).
Каждый лист — настоящий А4 210×297 мм с полями ЕСКД, содержимое
центрировано в текстовой зоне 170×257 мм.

**Пачка** — для отчёта из нескольких работ: каждой схеме рисуется свой
файл, но **размер фигур, масштаб и сам лист общие на всю пачку** — блоки
во всех схемах одинаковые (ГОСТ 19.701-90 п. 4.1.3), и все страницы
лабы совпадают до миллиметра. Одинаковые имена получают префикс папки:
`1/main.c -> 1-main.svg`.

```bash
gostpadi 1/*.c 2/*.gvn 3/*.gvn -o out/   # вся лаба: один лист, один масштаб
```

Если пачка не влезает в книжный лист, движок возьмёт альбомный
(297×210 мм) — но один на всю пачку, чтобы страницы совпадали. Флаг
`--landscape` задаёт ориентацию принудительно. Если масштаб всё равно
опустился ниже читаемого, утилита скажет об этом, а не выдаст тихо
нечитаемый лист.

### Что понимается в коде

| конструкция | как рисуется |
|---|---|
| `printf` / `scanf` | параллелограмм ввода-вывода |
| присваивания, `x = expr` | прямоугольник «процесс» |
| `if / else if / else` | ромб, ветки «да/нет», каскад — вертикальным стволом |
| `switch / case / default` | ромб, кейсы на шине; большой (5+) — сеткой в 2 колонки |
| `while` / `for` / `do-while` | шестиугольник «подготовка», тело возвращается в боковую вершину; у `do-while` в заголовке стоит `do while`, потому что в C условие проверяется после тела |
| `return` | скруглённый терминатор, конец ветки |
| `break` | обычный прямоугольник процесса, как в коде; рельса выхода из цикла не рисуется |
| `continue` | рельса к выходу нижней трапеции цикла (следующая итерация) |
| объявления переменных | выбрасываются |

`goto` не поддерживается — утилита скажет сама.

### Все опции

| опция | что делает |
|---|---|
| `-o ФАЙЛ/ПАПКА` | имя результата; для пачки — папка (или имя рядом с каждым входом) |
| `--labels=ru\|en` | язык надписей: «начало/конец» и «да/нет» или Start/End и yes/no (по умолчанию en) |
| `--font=N` | кегль текста в pt (по умолчанию 14), растит всю геометрию согласованно |
| `--lw=N` | толщина линий и усиков стрелок (по умолчанию 1.0) |
| `--no-split` | не резать длинную схему на листы: один лист без кружков-соединителей, в А4 его вписывает общий масштаб пачки (для вставки в отчёт — каждая схема на одной странице) |
| `--landscape` | альбомный лист А4 297×210 вместо книжного 210×297; на пачку влияет один раз |
| `--check` | проверить схемы: пересечения, наложения, один вход в «конец» |
| `--template` | заготовка .gvn на stdout |
| `-h, --help` | справка |
| `-V, --version` | версия |

## Свой формат .gvn

Если хочется управлять каждой строкой — пиши схему текстом:
строка = блок, ветки — отступом в 4 пробела.

```text
#gostpadi 1
input scanf("%d", &x)
y = x * 2
if y > 10
    yes: printf("big")
    no:
    while y > 0
        y = y - 1
output printf("done")
```

Строка = блок; ветки и тело цикла — отступом в 4 пробела; внутри ветки
можно вкладывать свои `if`/`switch`/`while` (ещё +4 пробела). Строка без
двоеточия после метки ветки продолжает её содержимое. `-> end` в конце
строки уводит ветку сразу в «конец».

Примеры — в [`examples/`](examples/), заготовка — по команде `--template`.

## Сайт

**[sehaxe.github.io/gostpadi](https://sehaxe.github.io/gostpadi/)** —
тот же движок, что и в CLI, собранный в WASM: перетащи один или несколько
файлов — схемы рисуются прямо в браузере за миллисекунды, код никуда
не отправляется. Скачивание SVG и PNG, шеринг ссылкой на код.

## Как устроен движок

Rust, ноль зависимостей (только парсер C `lang-c`), вывод — SVG без
промежуточных растров. Конвейер: код C → текст `.gvn` → раскладка
по модульной сетке (пересечения линий и наложения блоков исключаются
инвариантами) → SVG с одним `<g transform>` на страницу. Геометрия
страницы живёт в одном модуле `sheet`: его спрашивают и порезка, и
рендер, и он же решает, книжный лист или альбомный. Формат чисел,
сборка документа и записи в буфере — без промежуточных аллокаций.

## Разработка

```bash
cargo test                                 # 148 тестов: парсер, раскладка, рендер, CLI
cargo clippy --all-targets -- -D warnings  # линтер
cargo fmt --check                          # форматирование
```

на main автоматически. Локальная пересборка:

```bash
CARGO_PROFILE_RELEASE_OPT_LEVEL=z cargo build --release --lib \
  --target wasm32-unknown-unknown
cp target/wasm32-unknown-unknown/release/gostpadi.wasm docs/
```
